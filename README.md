# Jailbreak Harm Category Classification

Multi-class NLP classification of adversarial jailbreak prompts into 16 safety-policy violation categories using the **JailBreakV-28K** dataset.

## Project overview

This repository contains the end-to-end course project notebook for classifying a text prompt (`jailbreak_query`) into its corresponding safety-policy label (`policy`).

The notebook covers:

- Dataset loading from Hugging Face or a local Parquet cache
- Exploratory data analysis
- Class-distribution and text-length analysis
- Duplicate detection
- Text preprocessing and label encoding
- Classical machine-learning baselines
- RNN/GRU/LSTM models with word embeddings
- Bidirectional recurrent models
- BERT fine-tuning
- Validation and held-out test evaluation
- Confusion matrices and model comparison
- Error analysis
- Ensemble evaluation
- An ablation study examining `redteam_query`
- Export of deployment artifacts for the best Logistic Regression model

## Models evaluated

The notebook evaluates several model families, including:

1. Logistic Regression
2. Multinomial Naive Bayes
3. Random Forest
4. SimpleRNN
5. GRU
6. LSTM
7. Bidirectional SimpleRNN
8. Bidirectional GRU
9. Bidirectional LSTM
10. BERT Base (`bert-base-uncased`)

The notebook describes multiple hyperparameter configurations for the benchmark.

## Important methodological note

The notebook reports an ablation comparing `jailbreak_query` alone with `jailbreak_query + redteam_query`. It flags the near-perfect performance of the latter configuration as **suspected label leakage** rather than treating it as a genuine performance improvement.

For a fair classification setup, the primary input should therefore remain `jailbreak_query`.

## Quick start

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/jailbreak-harm-category-classification.git
cd jailbreak-harm-category-classification
```

### 2. Create a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For GPU-enabled TensorFlow/PyTorch installations, consult the official installation instructions for your hardware and operating system.

### 4. Launch Jupyter

```bash
jupyter notebook
```

Open:

```text
notebooks/jailbreak_harm_category_classification.ipynb
```

Run the notebook from top to bottom.

## Reproducibility

The notebook sets the main random seed to `42`. It also creates output folders automatically.

Generated outputs include:

- `figures/`
- `artifacts/results/`
- `artifacts/splits/`
- `deployment/`

Large datasets and binary model artifacts are intentionally excluded from Git by `.gitignore`. This keeps the GitHub repository lightweight and reproducible.

## Deployment artifacts

The notebook contains a deployment section that saves:

- `deployment/logistic_regression_model.joblib`
- `deployment/tfidf_vectorizer.joblib`
- `deployment/label_encoder.joblib`
- `deployment/preprocessing.py`
- `deployment/metadata.json`

These are generated locally after the notebook is run. They are not committed by default.

A lightweight inference helper is provided in `src/inference.py`.

## Scope and responsible use

This project is an academic/research implementation for classifying adversarial prompts by policy category. It should not be treated as a complete safety system, moderation service, or guarantee of safe/unsafe behavior.

Model predictions can be wrong, especially on distribution shifts, novel jailbreak techniques, ambiguous prompts, and underrepresented policy categories.
